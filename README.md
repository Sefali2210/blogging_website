# Wild & Wonderful — Blogging Website

A responsive animal-themed blogging website made with plain HTML, CSS and JavaScript.

## GitHub Pages
Repository: https://github.com/Sefali2210/blogging_website

After adding `index.html`:
1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Click **Save**.
5. Your project site will be available at:
   https://sefali2210.github.io/blogging_website/

GitHub Pages publishes static HTML/CSS/JavaScript from a repository.
